# ДТЕК Тетріс

Тетріс, де поле й фігури виглядають як графік відключень ДТЕК. Світла й темна теми; при програші все поле вкривається відключеннями.

Керування: стрілки або WASD, пробіл — скинути, P — пауза. На телефоні — свайпи (тап — поворот).

## Локальний запуск

```
python3 -m http.server 8080
```

і відкрити http://localhost:8080.

## Деплой на GitHub Pages

1. Settings → Pages → Source: **GitHub Actions**.
2. Actions → «Deploy to GitHub Pages» → Run workflow (або просто зробити push).
3. Адреса: `https://<користувач>.github.io/<репозиторій>/`.

Workflow запускається на будь-який push. Якщо в Settings → Environments → github-pages обмежено гілки деплою, додайте туди робочу гілку або змерджіть у `main`.
